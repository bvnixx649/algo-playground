# Algo Playground

Interactive lessons for 254383 Algorithm Design and Analysis:
Space–Time Trade-offs, Dynamic Programming and Greedy Technique.
Every lesson cites its slide deck and page numbers.

Open the site: https://bvnixx649.github.io/algo-playground/

Every lesson steps through the slide examples one move at a time, lets you change the input,
and ends with exam-style questions. It is plain HTML/CSS/JS with no build step.

There is also a page for the old paper (69-1-254383-2, 25 questions) with instant checking: `#exam`,
and a filled-in worksheet for P, NP and NP-Complete with a 15-question self-test: `#np`.

Run locally: `python .serve.py` then open http://127.0.0.1:5178

Check the lesson algorithms against brute force: `node test.js` (no dependencies).
