# Algo Playground

Interactive lessons for 254383 Algorithm Design and Analysis, weeks 11–15 (post-midterm):
Space–Time Trade-offs, Dynamic Programming and Greedy Technique.

Open the site: https://bvnixx649.github.io/algo-playground/

Every lesson steps through the slide examples one move at a time, lets you change the input,
and ends with exam-style questions. It is plain HTML/CSS/JS with no build step.

Run locally: `python .serve.py` then open http://127.0.0.1:5178
